# Security Policy

## Reporting a Vulnerability

If you find a security issue in this repository, please report it privately by reporting a vulnerability via github security tab.
Do not create a public issue for security vulnerabilities.
We will respond to your report as soon as possible and work with you to resolve the issue.

## Supported Versions

We actively maintain and monitor the security of the following versions:

| Version | Supported          |
|---------|--------------------|
| 1.x     | :white_check_mark: |

## Security Updates

We will review and address security vulnerabilities in supported versions as quickly as possible.
Security patches will be released as needed.
